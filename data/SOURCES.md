## Details

### Credit-card fraud (ULB Machine Learning Group, European cardholders)

- **Source:** [OpenML dataset 1597 (Worldline and ULB Machine Learning Group)](https://www.openml.org/d/1597)
- **Licence:** Database Contents License (DbCL) v1.0 (Kaggle release); OpenML: public
- **Cite as:** Dal Pozzolo, A., Caelen, O., Johnson, R. A. & Bontempi, G. (2015). Calibrating probability with undersampling for unbalanced classification. IEEE SSCI, 159-166. doi:10.1109/SSCI.2015.33
- **Unit of observation:** transaction
- **Lectures:** L1, L2, L3, L8, L11
- **Notes:** Full data: 284,807 transactions, 492 frauds (0.173 %), 143.8 MB raw (kept in data/raw/, not committed). The committed file keeps all frauds and a 10 % random sample of the legitimate transactions (seed 20261108); column weight = inverse sampling rate, so weighted statistics reproduce the full data. V1-V28 are PCA (principal component analysis) components released by the data owner; Time = seconds since the first transaction; Amount in EUR; row_id = row in the full file.
- **`data/clean/creditcard_fraud_sample.csv`** (28,924 rows, 8.4 MB; September 2013 (2 days); all frauds + 10 % random sample of legitimate transactions): columns `row_id`, `Time`, `V1`, `V2`, `V3`, `V4`, `V5`, `V6`, `V7`, `V8`, `V9`, `V10`, `V11`, `V12`, `V13`, `V14`, `V15`, `V16`, `V17`, `V18`, `V19`, `V20`, `V21`, `V22`, `V23`, `V24`, `V25`, `V26`, `V27`, `V28`, `Amount`, `Class`, `weight`

### German credit (Statlog): credit scoring of 1,000 loan applicants

- **Source:** [UCI Machine Learning Repository, dataset 144 (H. Hofmann, University of Hamburg)](https://archive.ics.uci.edu/dataset/144/statlog+german+credit+data)
- **Licence:** CC BY 4.0 (Creative Commons Attribution 4.0)
- **Cite as:** Hofmann, H. (1994). Statlog (German Credit Data). UCI Machine Learning Repository. doi:10.24432/C5NC77
- **Unit of observation:** applicant
- **Lectures:** L1, L3, L11
- **Notes:** Categorical attributes keep the UCI codes (A11, A12, ...; code book in the UCI page); default = 1 for a bad credit risk (300 of 1,000). The UCI cost matrix weights a missed bad risk 5 times a rejected good one.
- **`data/clean/german_credit.csv`** (1,000 rows, 78 KB; 1,000 loan applicants of a German bank): columns `checking_status`, `duration_months`, `credit_history`, `purpose`, `credit_amount_dm`, `savings_status`, `employment_since`, `installment_rate_pct`, `personal_status_sex`, `other_debtors`, `residence_since`, `property`, `age_years`, `other_installment_plans`, `housing`, `existing_credits`, `job`, `num_dependents`, `telephone`, `foreign_worker`, `default`
